# 从一个信号，到业务的下一步

2026-09-13 正式版动效适配。完整视觉方向见 [流动的智能](visual-style-v2.md)。本轮用连续粒子丝带替换第一轮的模块拱桥，并将同一视觉语言扩展到首页、产品与方案、案例与实践三页。

## 叙事

兰芯把分散的客户需求理解成可跟进的信息，再把信息接入真实工作。首屏右侧的有机光带经历三个阶段，左侧标题和入口始终是独立 HTML：

1. **看见信号**：点光散落在丝带周围，显现潜在方向。
2. **建立连接**：粒子逐渐聚合到连续曲面，形成关系。
3. **推动行动**：光流沿完整丝带前行，保留轻微空间运动。

首次进入演绎聚合，之后维持光流。鼠标影响观察角度；重看从头开始，选幕从该阶段起点继续播放，不接管滚轮。正式版默认开启动效，移除首屏与全局暂停按钮，也不再恢复预览版留下的暂停状态。系统减少动效与节省流量设置仍可触发静态回退。

LeadsHunter 的边缘流光聚焦线索；VECT 用星群连接关系；TACT 用定向光流推进工作；培训用上升曲线生长；实践用环流围绕成果；方法区用接续路径表达步骤；联系区重新汇聚。子页面页头采用横向流场。动效不承载产品数据，也不虚构客户或收益。

## 实现

Hero 适配自 ThreeUI Community [Orbital Sphere](https://github.com/MengTo/threeui/blob/68802d5428071ada5c20db8094b1649e6bb770ed/src/shaders/orbital-sphere/orbitalSphereRenderer.ts) 的粒子几何与轨道场景，使用自定义顶点着色器生成扭转丝带、柔和圆点和通透曲面。Flow Field / Constellation Field 提供其它场景的运动参考，局部效果以 Canvas 2D 实现。MIT 许可保留于源码及构建包，详见 `THREEUI-LICENSE.txt`。

- 依赖固定 Three.js 0.186.0、esbuild 0.28.2，全部本地打包。
- 场景源：`scripts/motion/hero-scene.js`；独立生成包：`company-hero-scene.js`。
- Hero 控制器：`company-hero-motion.js`；8 类区块粒子场：`company-particle-fields.js`。
- 预览偏好清理：`company-motion-preference.js`；共享叙事时间轴：`company-motion-timeline.js`；统一风格：`company-luminous.css`。
- Hero 桌面 20,000 粒子、手机 6,500 粒子；DPR 分别上限 1.7 / 1.25，最高约 30 fps。
- 局部粒子场共享一个最高 30 fps 调度器；每场景桌面 55–110、手机 32–48 粒子；运动速度调整为第二轮初版的 42%，只绘制可见区域。
- 同一时间轴驱动 Three 场景与三段进度：0–1.8 秒为信号，1.8–6.2 秒为连接，6.2–8.5 秒为行动；此后三段完成，丝带保持环境光流。连接、行动的着色器聚合值来自各段真实进度的平滑曲线。进度线逐段填充，当前圆点随实际进度移动。
- 旧版错位来自控制器 2.8/6.7 秒与着色器 1.8/6.2/8.5 秒两套阈值，以及不随时间填充的静态轨道。本版两者共用同一次时间轴计算，重看和选幕同时重置帧基准，不引入重播跳帧。
- 离屏、后台和缓存离开停止调度；返回沿用原时刻，不跳帧。缓存期间排队的按钮回调不改变叙事位置。
- 减少动效 / saveData 释放 Hero、隐藏区块画布；无 WebGL、初始化或渲染失败回到静态图。
- 浅深色读取共享主题控制器给出的 `html[data-theme]`，响应 `lan:theme-change`。用户手动选择优先于系统；主题变化只重绘调色板，不重建场景或重置时间。独立加载无共享主题时仍跟随系统。主题切换、窗口缩放失败也有回退；页面离开释放几何、材质、画布及监听。

## 静态视觉

两色 Hero 由内置图片生成工具制作，提示词与资产记录在 [视觉方案](visual-style-v2.md#图片与提示词)。提供 768 / 1280 / 1672 宽 WebP 与 PNG 原图。始终保留高优先级、响应式、无障碍的装饰 picture；文案不烘焙进图片。
